The Milestone Badge is the atomic unit of milestone UI—a compact tile that celebrates user progress, with locked and unlocked states, progress, and rarity built in. Compose with [Milestone Card](/docs/components/milestone-card) and [Milestone Grid](/docs/components/milestone-grid) when you need to show milestones at scale.

## With Trophy

Use the [Trophy SDK](https://docs.trophy.so/api-reference/client-libraries) to fetch a user's milestones server-side. Milestones are served by Trophy's achievements API:

<OpenApiCodeSamples
  spec="application"
  method="get"
  endpoint="/users/{id}/achievements"
/>

Then pass the response into `MilestoneBadge` props in your UI layer:

```tsx
const milestone = response[0]

<MilestoneBadge milestone={milestone} />
```

## API Reference

| Prop               | Type                                | Default     | Description                   |
| ------------------ | ----------------------------------- | ----------- | ----------------------------- |
| `milestone`        | `UserMilestone`                     | Required    | Milestone data for this badge |
| `badgeSize`        | `"sm" \| "default" \| "lg" \| "xl"` | `"default"` | Badge size                    |
| `onMilestoneClick` | `(milestone) => void`               | -           | Click handler                 |

### Types

```ts
interface Milestone {
  id: string
  name: string
  trigger: "metric" | "api" | "streak"
  badgeUrl?: string | null
  progress?: number // optional series progress from 0 to 100, unlocked only
  rarity?: number // optional rarity from 1 to 100 shown as "X% of users"
}

interface UserMilestone extends Milestone {
  achievedAt: string | null // null = locked
}
```
