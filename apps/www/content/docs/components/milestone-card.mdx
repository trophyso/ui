## With Trophy

Use the [Trophy SDK](https://docs.trophy.so/api-reference/client-libraries) to fetch a user's milestones server-side. Milestones are served by Trophy's achievements API:

<OpenApiCodeSamples
  spec="application"
  method="get"
  endpoint="/users/{id}/achievements"
/>

Then pass and transform the response into `MilestoneCard` props in your UI layer:

```tsx
const milestones = response
const highlightedMilestones = milestones.slice(0, 3)

<MilestoneCard
  highlightedMilestones={highlightedMilestones}
  milestones={milestones}
/>
```

## API Reference

| Prop                    | Type                                      | Default       | Description                                                       |
| ----------------------- | ----------------------------------------- | ------------- | ----------------------------------------------------------------- |
| `highlightedMilestones` | `UserMilestone[]`                         | Required      | Separate featured milestones shown in the top section             |
| `milestones`            | `UserMilestone[]`                         | Required      | List milestones rendered in the lower section and used for totals |
| `badgeSize`             | `"sm" \| "default" \| "lg"`               | `"default"`   | Badge size used by the lower list                                 |
| `lockedStyle`           | `"grayscale" \| "silhouette" \| "hidden"` | `"grayscale"` | Locked row presentation in the embedded `MilestoneList`           |
| `onMilestoneClick`      | `(milestone) => void`                     | -             | Click handler for badges and list rows                            |
