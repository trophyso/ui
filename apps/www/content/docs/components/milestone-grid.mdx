## With Trophy

Use the [Trophy SDK](https://docs.trophy.so/api-reference/client-libraries) to fetch a user's milestones server-side. Milestones are served by Trophy's achievements API:

<OpenApiCodeSamples
  spec="application"
  method="get"
  endpoint="/users/{id}/achievements"
/>

Then pass the response into `MilestoneGrid` props in your UI layer:

```tsx
<MilestoneGrid milestones={response} />
```

## API Reference

### MilestoneGrid

| Prop               | Type                        | Default     | Description                    |
| ------------------ | --------------------------- | ----------- | ------------------------------ |
| `milestones`       | `UserMilestone[]`           | Required    | Array of milestones to display |
| `columns`          | `2 \| 3 \| 4 \| "auto"`     | `"auto"`    | Number of grid columns         |
| `gap`              | `"sm" \| "default" \| "lg"` | `"default"` | Gap between grid items         |
| `badgeSize`        | `"sm" \| "default" \| "lg"` | `"default"` | Size of milestone badges       |
| `onMilestoneClick` | `(milestone) => void`       | -           | Click handler for milestones   |

### Types

```ts
interface Milestone {
  id: string
  name: string
  trigger: "metric" | "api" | "streak"
  badgeUrl?: string | null
  progress?: number // optional series progress from 0 to 100, unlocked only
  rarity?: number // optional rarity from 1 to 100 shown as "X% of users"
}

interface UserMilestone extends Milestone {
  achievedAt: string | null // null = locked
}
```
